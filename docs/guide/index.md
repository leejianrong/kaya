# kaya

<p style="font-size: 1.15rem; color: var(--md-default-fg-color--light);">
A markdown notes app that agents can actually use.
</p>

---

**Source code**: <https://github.com/leejianrong/kaya>

---

kaya is a cloud-hosted markdown notes app with a REST API underneath it, a command-line client on
top of that, and an MCP server next to it. The web UI is one client among three, not the only way
in — anything you can do in the browser editor, an agent can do with a tool call.

This site is a work in progress: this page and its sibling sections are placeholders while the
real content lands (EPIC-172).
